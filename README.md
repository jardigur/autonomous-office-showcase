# Autonomous Multi-Agent Virtual Office Architecture

Technical showcase and architecture topology of an autonomous multi-agent virtual office operating physical automotive workshop transactions, telemetry, and business workflows.

## Features
- **Topology Interactive Canvas**: Built with `@xyflow/react` and touch-lock gesture handling.
- **Audited Metrics**: Comprehensive telemetry snapshot showing OPEX reductions and token utilization.
- **Hardware & Concurrency Proofs**: Mutex locks for thermal printing and automated lifecycle triggers.
- **Zero-PII Pipeline**: Automated prebuild security hook validating that no sensitive personal or workshop data is leaked.

## Deployment
Deployable with zero configuration to Vercel or Cloudflare Pages.
```bash
npm install
npm run build
```
